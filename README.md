# 🚚 Container OCR & Reconciliation WebApp (V3)

ระบบเว็บแอปพลิเคชันจัดการโลจิสติกส์ตู้คอนเทนเนอร์แบบครบวงจร: สแกนใบงานคนขับรถบรรทุก (Truck Job Sheets) ด้วย AI (Google Gemini Vision), จับคู่เลขตู้กับฐานข้อมูลงานหลัก (Master DB) แบบ Real-time, จัดการข้อมูลรถและคนขับ, คำนวณค่ารอบและเงินเดือน, บันทึกค่าใช้จ่ายรถ และสำรองไฟล์ขึ้น Google Drive อย่างเป็นระบบ

---

## ✨ คุณสมบัติหลัก (Key Features)

1. **AI Vision OCR (Google Gemini Fallback Hierarchy):**
   - สแกนใบงานอัตโนมัติด้วย Multi-model Fallback (`gemini-3.7-flash` 🥇 ➡️ `3.5` ➡️ `3.0` ➡️ `2.5` ➡️ `3.1-flash-lite` โควต้า 500 ครั้ง/วัน)
   - บีบอัดภาพผ่าน Canvas อัตโนมัติ สแกนได้คมชัด รวดเร็ว
2. **ระบบตรวจเทียบ 25 บรรทัดคงที่ (Fixed 25 Rows Standard):**
   - ตารางตรวจเทียบตรึง 25 แถว (`#1` - `#25`) ตามแบบฟอร์มกระดาษจริง 1:1
   - ระบบ **Hover-to-Reveal Strikethrough (`🚫 ขีดฆ่า`)** สำหรับบรรทัดยกเลิก โดยไม่นับเป็นข้อผิดพลาด
   - การจัดแนว Monospace 1:1 ระหว่างช่องพิมพ์กับข้อความดิบ OCR
3. **สมองกลตรวจเทียบ 4 สี (Color Coding Matching Logic):**
   - 🟢 **ตรง 100% (Green):** เลขตู้ตรงเป๊ะ ยืนยันอัตโนมัติ
   - 🟣 **ตู้ซ้ำในรอบงาน (Indigo):** ตรวจจับตู้ซ้ำ Dis/Load และเลือกงานให้อัตโนมัติ
   - 🔵 **ใกล้เคียงสูง (Blue):** ความคล้าย >= 85% แทนค่าและจับคู่อัตโนมัติ
   - 🟡 **ตัวแนะนำ (Yellow):** มีตัวเลือกใกล้เคียงหลายตัว คงข้อความดิบให้ผู้ใช้เลือก
   - 🔴 **ไม่พบใน DB (Red):** เลขตู้ไม่ตรงในฐานข้อมูล พิมพ์ค้นหาหรือสลับตู้ได้อิสระ
4. **ระบบบริหารจัดการรถและคนขับ (Fleet & Driver Management):**
   - จัดการทะเบียนรถ, ประวัติพนักงานขับรถ, งวดการขับขี่ และประวัติการครองรถแบบ Real-time
   - ระบบบันทึกค่าซ่อมบำรุงและประวัติการลางานอัตโนมัติ
5. **ศูนย์รวมรายได้คนขับ (Driver Payroll Hub 5 Tabs):**
   - สรุปค่ารอบตู้ตามเรทขนาดตู้, โบนัสขั้นบันได, ฐานเงินเดือน, ยอดหักประกันสังคม (875฿), ภาษี 3%, รายการเบิกเงินล่วงหน้า และประวัติการตัดจ่ายเงิน
6. **ระบบบันทึกค่าใช้จ่ายรถเบ็ดเสร็จ (Unified Truck Expenses):**
   - บันทึกและนำเข้าไฟล์ Excel ค่าน้ำมัน, ซ่อมบำรุง, ผ่านท่า, ผ่อนรถ และภาษี/พ.ร.บ.

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Getting Started)

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้นรัน Dev Server
npm run dev

# 3. หรือดับเบิลคลิกไฟล์ Batch เพื่อรันอัตโนมัติ
run_webapp.bat
```

---

## 🛠 Tech Stack
- **Frontend Framework:** React 19 + Vite (Vanilla CSS Tokens, Glassmorphism UI)
- **Database & Auth:** Supabase (PostgreSQL + RLS + Stored Procedures)
- **AI Engine:** Google Gemini API (v1beta)
- **Cloud Storage:** Google Drive API (v3)
